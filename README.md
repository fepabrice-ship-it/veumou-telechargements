# Veumou : téléchargements

Ce dépôt sert uniquement à distribuer l'application Android **Veumou**.

Pour installer l'appli, passez par le site : **https://veumou.vercel.app**

Les fichiers se trouvent dans les [Releases](../../releases/latest) :
- `veumou.apk` : la version à prendre (téléphones Android récents, 64 bits) ;
- `veumou-universel.apk` : pour les téléphones plus anciens.
